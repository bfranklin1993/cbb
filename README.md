# College Basketball Manager

A text-based college basketball management and simulation game.

## Features
- Manage real college basketball teams
- Auto-simulated games based on team attributes and strategies
- Choose offensive and defensive systems
- Full season play with conference schedules
- NCAA Tournament and NIT post-season
- Player development throughout career
- Multi-season career mode

## How to Play
```bash
python main.py
```

## Requirements
- Python 3.7+

## Game Systems

### Player Attributes (1-10 scale)
- Shooting
- Defense
- Athleticism
- Basketball IQ
- Rebounding

### Offensive Systems
- Motion Offense
- Princeton Offense
- Fast Break
- Pick and Roll
- Isolation

### Defensive Systems
- Man-to-Man
- 2-3 Zone
- 1-3-1 Zone
- Full Court Press
- Pack Line
